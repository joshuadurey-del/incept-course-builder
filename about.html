About Incept Course Builder

Create a new course design or test the complete native TimeBack pipeline with a small course of your own.

The startup menu offers a new course build, a new test course, or a saved course built here. A regular new build saves your brief and design work order, then pauses at design. The small test route is the executable path through generation, native QC, publication, learner verification and launch.

Native tools do the work

The test uses Content Factory, AlphaVideo and the native TimeBack tools. One lesson, an article, a video, five article checks and a small set of placement, mastery, unit and final assessments exercise the pipeline, including a graded written response.

New identities only

Each test starts with fresh course and content identities. The Builder resumes its own saved builds; it does not import or modify existing TimeBack courses.

Evidence before launch

Generation and publication are separate from acceptance. Watch the saved video, review its QC and complete the activities as a learner. Check scores, feedback, XP and completion before approving launch.

Keep your run evidence

Frozen configuration, requests, approvals and service responses stay in the run folder. Credentials remain in an owner-only local file. This public site provides product documentation; the installed Builder manages your work.

Start on your Mac

Open Terminal and run the installer:

curl -fsSL https://joshuadurey-del.github.io/incept-course-builder/install.sh | bash
  1. Sign in to GitHub. Use an account with a verified @alpha.school email and access to the private InceptTrilogy package.
  2. Choose your starting point. Start a design, create a new test course, or resume a build you created here. The default test title is Automated Test Course 01.
  3. Connect the real services. The test menu saves your TimeBack application credentials and organization, Content Factory key and AlphaVideo connection. You also need an authorized AWS profile for native media storage, plus uv, the AWS CLI and FFmpeg. The Builder prepares the pinned SDK in an isolated Python runtime.
  4. Review the costs. Approve a supported estimate for generation, render, item QC, video QC and storage before paid calls. An unknown price stays unmeasured; a saved budget is not a service-enforced spending cap.

Return to the menu with:

~/.local/bin/incept-course-builder

Use incept-course-builder status for saved build status or incept-course-builder open for the selected build’s local page. Updates preserve your local work and credentials. Opening a page or leaving the menu does not prove a course is live.

Continue with the work already saved

The test records real hosted job IDs as soon as they exist and keeps their original responses. Resuming checks those jobs instead of resubmitting the whole build. A blocked service holds its dependent work while independent lanes can continue.

Before a new render, review the shared video queue. Only jobs you explicitly confirm as abandoned are canceled; other work is preserved. Before publication, watch the saved video and review the new-course plan. Before launch, use your bound TimeBack learner account to complete the course and record the required acceptance evidence.

The small test checks the complete workflow at a limited scope. It does not certify a full AP curriculum or guarantee a completion time.
