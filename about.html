About Incept Course Builder

One command that builds an Alpha course with the factory’s native tools and leaves evidence you can inspect.

Start from a course id. The build fetches what the factory already holds, derives what it can, asks you once for what only you hold, and hands the rest to a work order. A local page shows where the course is: blueprint, course map, lessons with checks, bank gates, publish dark, cold QC, walk, open.

Native tools do the work

Content Factory, AP One, and TimeBack remain the authoritative course systems. The builder brings together their existing course workflows, tools, and verification requirements. Align, Synthesize, Assemble, and Prove organize the view; each course retains its native process.

No model in the loop

The back end is a make-style dependency graph of files. A model is called only on a work order, sized for a local 30B model, as a compiler; the free prescreen and the factory’s paid judge decide. Service credentials stay in an owner-only file or the native provider.

Coverage before completion

Required content populations have separate acceptance, integration, and served evidence. A passing bank proves its own scope. Missing measurements stay UNMEASURED, and a published position retains its source date.

Public status, private work

This site displays published observations and documentation. The private package requires authorized Alpha/Incept GitHub access. Course content, local checkpoints, credentials, and private runbook resources belong in the authorized workspace.

Start on your Mac

Open Terminal and run the installer:

curl -fsSL https://joshuadurey-del.github.io/incept-course-builder/install.sh | bash
  1. Sign in to GitHub. Use an account with a verified @alpha.school email and access to the private InceptTrilogy package.
  2. Pick your course from the menu. Setup checks the available local tools. Native services and selected workflows may require their own runtime and authorization.
  3. The build takes it from here. It inspects the whole course, plans the work and resolves routine setup. Follow progress in your persistent dashboard; only missing inputs come back to you.
~/.local/bin/incept-course-builder build

Open the local dashboard later with ~/.local/bin/incept-course-builder. The dashboard stays available after Terminal closes. Run incept-course-builder stop to stop it. Updates reuse saved settings and reopen the dashboard. Model subscriptions are separate.

The build handles the workflow

Every value follows one order of resort: factory bytes at live main, derivation, the answer file, you once, a model on a work order, a person. Typing the one command is the owner word; a standing authorization is recorded and every paid call, landing and native write cites it. No gate is skipped because of it.

Five stops and nothing else is printed to you: the course is live; a check failed; network or sign-in; work orders open; an answer is needed. Native quality checks and the publication contract govern every step.

The public site shows the product and shared course evidence. Your installed application owns the local dashboard.
